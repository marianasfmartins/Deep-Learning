TINY IMAGENET PROJECT 2026
==========================

Contents
--------
images/      Image files used in the project
labels.csv   filename, class_id and class description

Task
----
Develop a deep-learning solution for multiclass image classification.

Students are responsible for:
- exploratory data analysis;
- data-quality assessment;
- definition of train, validation and test partitions;
- preprocessing;
- model specification and training;
- performance evaluation;
- error analysis;
- methodological justification.

Important
---------
Do not assume that the dataset has already been cleaned or partitioned
for modelling. All data-preparation decisions must be documented.
